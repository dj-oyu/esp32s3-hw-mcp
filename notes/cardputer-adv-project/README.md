# cardputer-adv-project — 兄弟プロジェクト固有の知識

このディレクトリは、**Cardputer ADV（= cardputer-adv-pocketjs プロジェクト）に固有の知識**を置く場所。
このリポジトリの `notes/` 直下にある番号つきノートは「**PIE 一般**（チップの命令・ハーネス・例題の作り方）」
を扱い、こちらは「**あちらのプロジェクトの実装・実測・制約**」を扱う。

## 何がどちらに入るか

| 置き場所 | 中身の例 |
|---|---|
| `notes/NN-*.md`（直下） | TRM の読み方、レジスタ表、PIE 命令の意味、エンコーディング検証、実機計測ハーネス、`examples/` の書き方 |
| `notes/cardputer-adv-project/`（ここ） | あちらの VM・描画・コーデックの実装事実、あちらの実測値（コストモデル・落とし穴）、シーン（flower など）の perf 事情、あちらに効く/効かないの判定 |

## 出典の書き方（このディレクトリの規約）

- どのリポジトリ・どのブランチの話かを**必ず頭に書く**。パスはそのリポジトリ内の相対パスで書く。
  例: 「cardputer-adv-pocketjs @ vm/main (74e704d)、`main/scene/flower.c:120`」
- 数値は **実機 / 実測(host) / [obj]（クロスコンパイラの静的カウント）/ 推定** のどれかを必ず添える。
- あちらの文書（`docs/pie-simd.md` など）から引くときは **節番号（§）と行番号の両方**を書く。
  あちらは活発に更新されるので、行番号だけでは指せなくなる。
- **あちらの repo に書けるものはあちらに書く。** ここに置くのは、こちらの MCP / 例題から引く必要がある
  もの・分野横断で参照するものに限る（実装の変更提案はあちらの issue / ブランチへ）。
